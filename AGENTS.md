# Proyecto Addlegal/Addveritas

## Descripción
Plataforma jurídica y académica para estudiantes de Derecho.

## Stack
- Next.js
- React
- TailwindCSS
- Supabase

## Reglas
- Usar componentes reutilizables
- Mantener estructura modular
- No usar estilos inline
- Usar Tailwind
- Priorizar diseño responsive
- Mantener naming limpio
- Separar lógica y presentación

## Diseño
- Moderno
- Juvenil
- Profesional
- Minimalista
- Elegante

## Colores
- Negro
- Blanco
- Dorado
- Gris oscuro

## Objetivo
Mostrar tutorías y permitir inscripción de estudiantes.
